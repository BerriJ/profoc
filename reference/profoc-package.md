# Package Info

Use multiple online-aggregation algorithms to combine probabilistic
forecasts using CRPS Learning as described in Berrisch, Ziel: "CRPS
Learning", 2021. The primary function of this package is called
`online`.

[doi:10.1016/j.jeconom.2021.11.008](https://doi.org/10.1016/j.jeconom.2021.11.008)
